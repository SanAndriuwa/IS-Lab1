# MATLAB files

- `main/`: original perceptron template, helper functions, photographs, and Data.txt. The template still contains unfinished training sections; it is not a completed solution. Use this folder as MATLAB Current Folder when working with the template.
- `additional/`: completed Naive Bayes task. Open `additional/lab1_bayes.m` and press Run. Keep Data.txt in that folder.
- `additional/bayes_from_lab1.m`: classifies features from the main task using P, T and Ptest. Add the additional folder to the MATLAB path before calling it.

The root README.md is the original assignment. Personal defense notes are kept in Notion.

Naive Bayes was checked independently: training accuracy 100%, test accuracy 87.5%. MATLAB execution has not been confirmed because MATLAB stopped before running the scripts in this environment.
